(1) Compared with plot-single.png, plot-multi.png shows that the execution time for each matrix multiplication is much higher when 10 processes run at the same time. In the single-process test, matrix multiplication took only about 0.3 seconds and used all of one CPU, while the concurrent runs took about 2.8 to 3.1 seconds each and showed CPU usage of roughly 16% to 18% per process.
(2) Compared with plot-multi.png, plot-taskset.png shows lower CPU usage for each process because all 10 matrix multiplication jobs are forced to run on the same CPU. In the multi-process test, each process used about 16% to 18% CPU, while in the taskset test each process used only about 9% to 10% CPU.
(3) Compared with plot-multi.png, plot-nice.png shows difference between processes because some jobs were given lower scheduling priority using niceness value. The normal-priority jobs generally completed faster, while the higher-niceness jobs took longer.
